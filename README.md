# Нитяные портреты

Превращает фото в портрет из нитей, натянутых между гвоздями по кругу пялец (string art).
Программа сама рассчитывает, между какими гвоздями натянуть нити, показывает, как портрет «натягивается», и записывает это в видеоклип.

**Открыть в браузере:** https://gregory-gittools.github.io/tool-thread-portraits/

Работает целиком в браузере (Chrome или Edge), ничего не устанавливается, фото никуда не отправляются.
Лицо и фон распознаёт нейросеть [MediaPipe](https://ai.google.dev/edge/mediapipe): она скачивается в браузер и работает в нём же.

## Как пользоваться

1. «Фото…» — выберите снимок (или перетащите его в окно). Можно начать с примера — Вермеера.
2. «✂ Кадрировать…» — наведите круг на лицо; кадрированное фото само сохраняется в примеры. «✨ Авто-настройка» подберёт нити и остальные настройки под фото (кадр не меняет).
3. «▶ Старт» — расчёт (1–2 минуты). Потом «▶ Старт» ещё раз покажет, как нити натягиваются по порядку.
4. «● Запись» — сохранить клип (mp4), «PNG» — картинку (только портрет, 2048×2048), «Схема» — список отрезков нити между гвоздями.

## Настройки

| | |
|---|---|
| Фон | оставить как на фото или убрать — тогда все нити идут на лицо и фигуру |
| Нити | белые на чёрном, чёрные на белом или цветные (цвета берутся из фото) |
| Гвоздей, линий | больше — подробнее; расчёт сам останавливается, когда новые нити уже не улучшают рисунок |
| Толщина нити | 15 — нити видны по отдельности, лицо чистое; толще — нити заметнее, но лицо грубее; тоньше — мягкий полутон |
| Точность цветного акцента | нить может плавно менять оттенок к середине — точнее губы, глаза, яркие пятна |
| Текстура нити | обычная, шёлк (с блеском), шерсть (неровная) — меняется сразу, без расчёта |
| От лица к краям | только порядок показа в клипе: сначала черты лица, края — в конце |
| Формат клипа | только пяльцы, вертикальный (Shorts, Reels), квадрат, горизонтальный (YouTube) |

Свои фото и наборы настроек можно сохранить — они хранятся в этом браузере.
Колёсико мыши приближает картину, H — скрыть панель.

## Как это работает

Жадный алгоритм: среди всех пар гвоздей и всех цветов нити выбирается линия, которая сильнее всего приближает рисунок к фото (с учётом полупрозрачности нитей).
Чтобы не пересчитывать десятки тысяч линий на каждом шаге, оценки лежат в очереди, а пересчитываются только линии, через которые прошла новая нить.
Первые нити считаются по размытому фото — паутина «хаоса» заполняет крупные пятна, потом проступают формы и детали.
Ошибка на чертах лица — глазах, губах, бровях, ноздрях — весит больше, поэтому они прорисовываются точнее. Где лицо и черты, находит нейросеть (без интернета — по цвету кожи).

Сравнить варианты расчёта на своих фото: `node tools/bench.mjs` (нужен Chrome; подробности — в начале файла).

Пример — «Девушка с жемчужной серёжкой» Яна Вермеера (ок. 1665, общественное достояние).
Идея порядка заполнения «сначала хаос, потом детали» навеяна работами Ани Абакумовой.
